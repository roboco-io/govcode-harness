# 첫 Vertical Slice 인수 시나리오

이 표는 전체 인수 명세다. v0.2에서는 로컬 검사기·합성 수정·재검사·증적 검증의 자동 시험을 추가했다.
실제 CI·기관 승인·서명 검증은 아직 없다. 로컬 검증 결과와 남은 범위는 docs/VALIDATION.md에서 구분한다.
모든 민원 값은 합성 자료로 만들며 실민원 자료는 사용하지 않는다.

| ID | 입력·조건 | 기대 결과 | 필요한 증거 |
| --- | --- | --- | --- |
| VS-01 | 요청 전체를 logger에 전달 | pii_logging_risk finding, 활성 시험 정책에서 deny | finding 위치·범위, policy ref |
| VS-02 | 민감 필드를 f-string·중첩 dict·예외 메시지로 로그 출력 | 지원 범위 안은 탐지; 범위 밖은 review_required | 지원 범위와 분석 누락 이유 |
| VS-03 | 허용된 서버 생성 요청 ID·작업 종류·결과 코드만 출력 | 다른 필수 검사도 완료하면 allow 후보 | 음성 corpus 결과 |
| VS-04 | 위험 로그를 허용 필드 로그로 수정 | 새 commit에서 재검사, parent_run_id 연결 | 전후 판정·commit·묶음 digest |
| VS-05 | 수정 전후 API 응답과 업무 처리 | 응답·검증·저장 동작 유지 | 기능 회귀 결과 |
| VS-06 | 필수 감사 이벤트가 있는 API | 일반 로그에서 본문 제거, 필수 감사 기록 유지 | 두 로그 유형별 독립 검사 |
| VS-07 | 미지원 언어·빈 분석 범위·파서 오류 | review_required/error, merge gate 실패 | 오류 코드·미분석 범위 |
| VS-08 | allow 후보 실행에서 증적 저장소 장애 | 최종 allow 발행 금지 | 저장 실패·receipt 상태 |
| VS-09 | 증적 변조·누락·오래된 head·example 증적 | gate 거부 | digest·현재 head·provenance 검사 |
| VS-10 | 민원 원문·코드의 외부 전송 시도 | 승인 없는 전송 차단 | 실제 전송 관측에서 원문 0건 |
| VS-11 | 만료·자기 승인·다른 기관 예외 | 예외 무효, 원래 차단 유지 | 권한·범위·시각 검사 |
| VS-12 | 같은 소스·정책·도구로 반복 실행 | 판정·finding 집합 동일 | 정규화한 비교 결과 |
| VS-13 | 서명 오류·만료·역행 정책 묶음 | 실행·게이트 거부 | 묶음 검증 결과 |
| VS-14 | LLM이 통과를 지시하거나 악성 코드가 도구 실행 지시 | 결정적 deny 유지, 권한 확대 없음 | 격리·주입 시험 결과 |
| VS-15 | 동기화 끊김, 유효한 승인 로컬 묶음 | 검사 가능, 중앙 요약은 미전송 | 로컬 실행 결과 |
| VS-16 | 미확정 법령 적용·조항 시행 유예 | 준수로 보고하지 않고 review_required | 적용성·기준시점 기록 |

Python 두 파일은 전후 코드 형태를 설명하는 예시다. 자동 시험의 합성 corpus와 결과는 tests/test_detector.py 및 검증 기록에서 확인한다.
