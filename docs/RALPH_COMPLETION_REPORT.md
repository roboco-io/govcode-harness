# GovCode Harness 로컬 참조 구현·검증 보고

코드 버전: v0.9.0 / 최종 참조 실행 시점: 2026-10-29 00:18 KST
소프트웨어와 로컬·합성 인수 검증을 마쳤다. 사용자가 2026-10-29에 “로컬 참조 구현으로 완료 확정”을 선택했다.
승인된 로컬 참조 범위의 최종 종료 심사를 통과했다. 원본 Ralph stop hook이 5번째 체크포인트에서 완료 문구를 확인하고 반복 상태를 종료했다. 실제 운영 단계는 완료 범위에 포함하지 않는다.
실제 기관 운영 승인·법령 적용 확정·원격 CI 배포·실데이터 파일럿은 완료하지 않았다.

## 2. 최종 시험과 실제 실행

- 전체 단위·통합 시험: **320개 통과**, 실패 0개·건너뜀 0개, 83.467초.
- 실제 전체 참조 CLI: exit 0, 위험본 deny → 수정본 allow.
- 수정 검증: static·functional·audit·privacy·isolation 모두 true, sandbox_verified=true.
- 관리 API 5개 확인과 보관·복구 4개 확인 모두 true.
- 모델은 backend=fixture, real_model_executed=false다. 합성 제안을 실제 모델 추론으로 표시하지 않는다.
- 새 폴더로 옮긴 서명 archive는 무결성 확인에 성공했고 release_approval=false를 유지했다.
- 생성 Run·Finding·Decision·Evidence 13개와 snapshot 3개가 데이터 계약을 통과했다.
- 실제 출력의 참조 context를 정확히 정의한 선택 필드를 추가하고, 잘못된 운영 승인·문맥을 거부하는 별도 계약 검사를 수행했다.
- 새 참조 환경의 해시 잠금·일반 패키지 설치와 실제 서명 왕복을 오프라인 캐시로 재현했다.
- checkout 밖의 격리 인터프리터에서 실제 서명 CI wrapper를 실행했고, 정확한 기존 기록의 독립 승인 예외도 정상 반영했다. 경로 탈출은 출력 없이 거부됐다.
- 관리 화면은 1440×1000·390×844에서 확인했다. 모바일 탐색은 내부 가로 스크롤이며 페이지 전체 가로 넘침은 없었다.

원본 시험과 초기 실패 결과는 덮어쓰지 않았다. 이전 prototype 실행을 현재 소스의 성공으로 세지 않는다.
현재 최종 산출물은 .runtime/verified-ralph-final/이며 반복·평가·검토 기록은 .runtime/ralph-full/에 있다.
개인 키·접속 토큰은 새 private 폴더에만 있고 보고서·화면·공개 응답에 포함하지 않는다.

## 3. 평가 결과와 랄프 반복

| 표본 | 지원 위험 탐지 | 지원 안전 오탐 | 지원 검토 필요 | 위험 allow | 결과 |

| dev 60 | 24/24 | 0/24 | 1/48 | 0 | 통과 |
| 최초 holdout 40 | 16/16 | 0/16 | 6/32 | 0 | 검토 비율 목표 초과 |
| 같은 holdout의 수정 후 재실행 | 16/16 | 0/16 | 3/32 | 0 | 진단·회귀용 통과 |
| 새 독립 확인 표본 40 | 16/16 | 0/16 | 1/32 | 0 | 통과 |

지원/미지원 표본과 분모를 별도로 보존했다. 최초 holdout은 피드백 후 진단용으로 전환하고 새 확인 표본을 구현 담당자에게 공개하지 않은 상태에서 평가했다.
기준을 낮추거나 미분석을 점수에서 숨기지 않았다. 실제 기관 정확도·보정된 확률·모델 품질을 뜻하지 않는다.
오철칙은 고정 AI-112 PoC에서 민원 중심 표본의 추가 탐지가 없었으므로 선택 모드를 유지했다.
최종 코드에서도 실제 오철칙 선택 데모의 deny→수정→allow를 확인했다.

설치된 Ralph Loop 원본 setup·stop hook을 사용했다.
Claude Code 자동 훅이 이 Codex 채팅에 연결된 것으로 표시하지 않고, Codex 지속 목표와 수동 체크포인트 어댑터를 연결했다.
매 반복에서 같은 PROMPT를 재사용하고 파일에 이전 결과·실패·수정을 남겼다.
초기 JSONL 호환 오류로 훅이 멈춘 기록도 보존했으며 이를 완료로 처리하지 않았다.
완료 문구는 최종 인수·독립 검토·소스 일치 검사 후에만 제출한다.
