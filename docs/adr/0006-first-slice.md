# ADR 0006: 민원 API 개인정보 로깅 위험을 첫 흐름으로 선택

상태: Proposed / 날짜: 2026-10-28

## 배경

민원 본문은 불필요한 로그 복제로 개인정보 처리 범위가 커질 수 있다.

## 결정

위험 로그 finding→merge gate deny→허용 필드 로그 수정→새 commit 재검사→전후 증적 연결을 첫 구현 단위로 삼는다.

## 대안 검토

전 법령·전 언어를 한 번에 처리하는 범용 엔진은 정확도와 증적 완결성 검증이 어렵다.

## 결과와 비용

첫 흐름은 병합·배포를 통제한다. 운영 민원 요청 실시간 차단과 필수 접속기록 삭제는 포함하지 않는다.

## 검증 조건

합성 양성·음성 사례, 기능 회귀, 필수 감사 기록 보존, 증적 실패·stale 결과 거부를 검증한다.
