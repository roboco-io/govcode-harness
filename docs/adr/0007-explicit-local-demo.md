# ADR 0007: 명시적 로컬 데모 실행 경계

상태: Accepted for local prototype / 날짜: 2026-10-28

## 배경

사용자가 첫 Vertical Slice를 실제 로컬에서 실행하도록 요청했다.
기관 승인된 정책 묶음·서명키·증적 보관 정책은 아직 없다.

## 결정

원본 스캐폴드의 예시 정책은 draft/disabled로 유지한다.
별도 local-demo 실행에서만 시험 정책을 적용하고 모든 runtime 메타데이터에 실행 모드를 기록한다.
기관 승인·정책 서명·법령 준수로 표현하지 않으며 운영 모드를 제공하지 않는다.

입력 분석은 Git HEAD의 읽기 전용 스냅샷을 사용한다. 작업 트리 변화는 통과하지 않는다.
데모는 새 합성 저장소에서 위험 예제와 수정 예제를 실제로 커밋하고 두 실행을 연결한다.
기존 사용자 코드를 자동으로 수정하거나 프로젝트 저장소를 자동 커밋하지 않는다.

로컬 증적은 원문을 제외한 실행 provenance·판정·finding·분석 범위와 파일 digest를 보관한다.
receipt는 로컬 기록·재검증의 완료를 뜻한다. unsigned manifest는 작성자 인증이나 삭제 방지를 증명하지 않는다.
검증 게이트는 현재 소스·도구·정책과 결과를 다시 대조한다.

## 한계

Python의 명시적으로 지원하는 구문만 검사한다. 미지원 흐름은 review_required 또는 error다.
Python 전체·언어 간 데이터 흐름·법령 전체 준수를 보장하지 않는다.
운영 서명·키 배포·보관 잠금·기관 권한·실제 CI 브랜치 보호는 후속 작업이다.
