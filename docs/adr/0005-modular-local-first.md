# ADR 0005: 모듈형 로컬 실행기 우선

상태: Proposed / 날짜: 2026-10-28

## 배경

초기 목표는 하나의 검사·수정·증적 흐름을 검증하는 것이다.

## 결정

파일 기반 계약과 로컬 CLI에서 시작한다. Python 합성 예제를 첫 지원 범위로 삼고 어댑터 경계로 언어를 확장한다.

## 대안 검토

초기부터 다수 마이크로서비스·관리 UI·메시지 브로커를 설치하면 첫 흐름 검증보다 운영 비용이 먼저 커진다.

## 결과와 비용

동시 실행과 관리 편의는 제한된다. 성능·조직 요구가 확인되면 저장소·서비스를 분리한다.

## 검증 조건

단일 입력 스냅샷으로 결정적 판정이 재현되고 지원하지 않는 언어는 오류·검토 필요로 보고한다.
