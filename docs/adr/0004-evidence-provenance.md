# ADR 0004: 입력 고정과 증적 provenance

상태: Proposed / 날짜: 2026-10-28

## 배경

수정 전 판정과 수정 후 판정이 다른 소스·정책 버전에서 생성될 수 있다.

## 결정

소스·묶음·도구 digest를 고정하고 새 commit은 parent_run_id로 연결한다. 파일 digest와 manifest, 서명, 저장 receipt를 별도로 검증한다.

## 대안 검토

최신 결과 한 파일을 덮어쓰는 방식은 전후 이력과 원인을 잃는다. 해시만으로 진위·삭제 방지를 주장하는 방식도 배제한다.

## 결과와 비용

저장소 보관 잠금·키 관리·접근 감사가 별도 필요하다. 증적 보유기간과 기록 분류는 기관이 정한다.

## 검증 조건

변조·누락·오래된 head·example provenance·보관 실패를 gate가 거부한다.
