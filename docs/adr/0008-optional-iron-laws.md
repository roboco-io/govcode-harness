# ADR 0008: 고정한 오철칙의 선택적 보완 검사

상태: 로컬 PoC에 한해 적용 / 날짜: 2026-10-28

## 배경

사용자가 오철칙의 고정 버전 실제 실행, 기존 검사와 비교, 판정·증적 연결을 승인했다.
원래 민원 예제의 request_body 로깅은 오철칙 AI-112 프로필에서 누락되는 것을 확인했다.

## 결정

기존 AST 검사를 유지하고 --with-iron-laws를 지정한 경우에만 외부 검사를 추가한다.
외부 도구는 소스 commit과 의존성 해시를 고정한 별도 Python 환경에 설치한다.
검사 입력은 커밋한 Python 소스의 임시 복사본이며 원본 저장소 설정·Git 정보·실행 코드는 전달하지 않는다.

외부 검사의 종료 코드 1을 일괄 deny로 바꾸지 않는다. 보고서의 검사 완료·범위·지적·신뢰 상한을 함께 읽는다.
코드 2, 미설치, 시간 초과, 불완전, 알 수 없는 형식은 오류다. 검토 필요 상태도 통과하지 않는다.
기존 검사와 외부 검사 가운데 더 엄격한 상태를 사용한다.

Finding에는 검사 도구와 버전을 구분하고 외부 규칙 ID는 정제한 보조 보고서에 보존한다.
로깅 정책과 외부 코드 위험 정책을 분리하며 어느 쪽도 법령상 의무나 기관 승인본으로 표시하지 않는다.
원본 보고서의 snippet·메시지·절대 경로는 증적에서 제외한다. 원본 보고서는 임시 공간에서 처리하고 제거한다.

혼합 검사 증적은 실행 모드·정제 보고서·실제 도구·환경 지문을 포함한다.
verify는 증적의 모드에 따라 외부 도구까지 다시 실행한다. 검증 시 외부 검사를 생략해 통과시키지 않는다.

## 도입 판단

이번 구현은 선택적 PoC다. 기본 검사기 대체나 기본 활성화를 승인하지 않는다.
합성 corpus의 추가 탐지·누락·오탐·미분석 결과와 실행 비용을 바탕으로 다음 범위를 결정한다.
오철칙 전체 규칙·언어·패치 컨테이너·승인 서명 기능을 이번 프로필로 검증한 것으로 표현하지 않는다.
