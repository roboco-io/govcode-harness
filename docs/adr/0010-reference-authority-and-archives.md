# ADR 0010: 참조 권한과 역사적 증적의 경계

상태: 로컬 참조 구현에 적용

## 결정

실제 Ed25519를 사용하되 모든 참조 권한은 synthetic_reference로 표시한다.
서명된 예외는 실행 ID가 아니라 commit·현재 도구·정책·재계산한 탐지 의미에 결합하고 양쪽 서명·기록 철회를 적용한다.
검증기는 동일하게 캡처한 바이트로 의미 검사와 해시를 계산한다. 서명 export는 이 manifest에 묶인 원문 없는 투영이다.
역사적 archive_integrity는 현재 CI 통과가 아니며 release_approval=false다.
외부 운영 신원·법령 판단·키 관리·보존 정책을 개발 키와 합성 역할로 대신하지 않는다.
