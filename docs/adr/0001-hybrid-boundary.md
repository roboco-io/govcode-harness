# ADR 0001: 기관 내부 실행과 선택적 중앙 관리

상태: Proposed / 날짜: 2026-10-28

## 배경

원본 코드와 민원정보의 처리 경계를 기관이 통제해야 한다.

## 결정

Runner·검사·정책 판정·원본 증적은 기관 내부에 둔다. 중앙 관리도 내부 설치할 수 있게 하고, 외부 연결은 승인된 정책 동기화와 최소 요약에 한정한다.

## 대안 검토

중앙에서 모든 원본을 분석하는 방식은 기관별 반출·분리망 조건에 대응하기 어렵다. 완전 수동 분산 관리는 정책 버전 일관성 관리 비용이 크다.

## 결과와 비용

로컬 설치·업데이트·키 배포 운영이 필요하다. 오프라인 철회 전파 지연을 명시한다.

## 검증 조건

외부 통신이 없어도 승인 묶음으로 검사하고, 만료 묶음·반출 금지 자료 전송을 거부한다.
