# ADR-0014 규정 팩 발행·잠금과 적용성 판단의 신뢰 경계

상태: 채택 / 기준일: 2026-10-29 / 범위: R7-C·R7-D

## 결정

팩 내용·버전은 불변이며 작성·제출·독립 승인·운영자 발행 서명을 함께 보존한다.
프로젝트 잠금은 프로필 digest, 전체 선택 팩·의존성, 작성자의 선택 요청과 독립 검토에 결합한다.
기존 PolicyBundle 형식에 새 필드를 섞지 않고 별도 서명 kind와 계약으로 검증한다. 실제 검증이 없는 구형 정책 연결은 오류로 거부한다.

철회는 키·팩·발행·승인·잠금·검토 기록에 적용한다. 오프라인 검증은 최소 epoch와 보호된 기대 digest를 함께 요구한다.
순번만 신뢰하면 폐기된 운영자 키로 다른 내용의 높은 순번 목록을 만들 수 있으므로 받아온 목록 자체의 hash를 자동 신뢰하지 않는다.
1시간 수명은 참조 신선도 정책이며 법정 기간이 아니다. 최신 신뢰·기준점 배포는 호출자의 책임이다.

조건 계산은 typed eq/in/all/any/not의 3값 논리다. 참조한 미확정 사실이 있으면 판정은 pending이다.
거짓 조건은 제외 후보이며 독립 서명 검토가 필요하다. 예시가 아닌 근거는 참 조건도 별도 적용성 검토를 요구한다.
작성자와 같은 actor의 다른 키도 독립 승인이 아니다. 검토로 unknown을 false로 바꾸거나 알려진 조건과 반대 결론을 강제하지 않는다.

## 영향

적용성 판단 완료는 요구 충족·게이트 allow가 아니다. requirements_evaluated=false와 operational_approval=false를 유지한다.
기존 코드 검사·승인·증적과 R7-A/B 프로필 계약은 보존한다. 산출물 검사·작업 완료·단계 게이트·화면 연동은 R7-E 이후다.
역사적 저장소 재생은 당시 수신 시각으로 검증하고, 현재 사용은 현재 시각·프로필·신뢰·철회 정보를 다시 확인한다.
