# ADR-0012 공공 프로젝트의 규정 충족 안내와 첫 사례의 구분

상태: 채택 / 기준일: 2026-10-29

## 배경

공개 소개가 개인정보 로깅에 집중되어 제품 전체 목적이 첫 구현 사례로 축소되어 보였다.
사용자는 공공 프로젝트에 적용되는 각종 규칙·가이드라인·법령을 자동으로 충족할 수 있게 안내하는 것이 목적이라고 명시했다.

## 결정

제품을 공공 프로젝트 수행 전반의 규정 충족을 안내하는 하네스로 설명한다.
개인정보 로깅은 첫 Vertical Slice와 현재 구현의 검증 경계로 남긴다.
요구·수행 작업·자동 검사·수정 지원·담당자 검토·승인·증적을 공통 제품 흐름으로 둔다.
후속 분야는 규정 팩과 검사·산출물 어댑터로 설계하며, 미구현 영역을 기존 시험으로 검증했다고 표시하지 않는다.

## 영향

PRD·README·아키텍처·후속 계획·가이드·브로슈어가 같은 제품 목적과 구현 경계를 설명해야 한다.
기존 v0.9.0 코드·태그·인수 결과의 의미는 바꾸지 않는다. 구체적인 적용 규정과 새 분야의 인수 기준은 별도 설계·검증 대상이다.
