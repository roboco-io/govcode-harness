# ADR 0003: 법적 의무·통제·정책 분리

상태: Proposed / 날짜: 2026-10-28

## 배경

법령이 특정 로깅 라이브러리나 검사기 사용을 직접 명령하는 것으로 오인될 수 있다.

## 결정

Source→Obligation→Control→Policy를 별도 객체로 둔다. 확인 상태, 적용성, 조항 시행 구간, 정책 승인 상태를 각각 기록한다.

## 대안 검토

하나의 정책 파일에 법령 문구와 실행 조건을 섞으면 개정·시행 유예·기관별 적용을 추적하기 어렵다.

## 결과와 비용

정책 작성자의 추가 작업이 생긴다. 대신 예시 정책을 법정 의무로 보고하는 오류를 줄인다.

## 검증 조건

미확정 적용성과 유예 조항은 자동 준수 통계에 포함되지 않고 example 정책은 자동 활성화되지 않는다.
