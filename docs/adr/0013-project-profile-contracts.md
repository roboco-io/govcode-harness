# ADR-0013 프로필 불변 버전과 독립 승인, 설치 가능한 공통 계약

상태: 채택 / 기준일: 2026-10-29 / 범위: R7-A·R7-B

## 결정

새 프로젝트 계약의 정본은 govcode_harness/contracts/에 둔다. 제안 단계의 packages/contracts/ 경로에서 옮겨 설치본에서도 중복 사본 없이 같은 스키마를 읽도록 한다. 기존 catalog·snapshot 스키마는 유지한다.
외부 스키마를 자동 조회하지 않으며 계약 형태·참조 검증과 실제 서명·권한·규정 적용 판단을 구분한다.

프로필 내용과 승인 상태를 분리한다. 내용은 revision·parent_digest로 불변 연결하고, 상태는 서명 동작의 추가 전용 이력에서 계산한다.
expected_revision은 잠금 안에서 대조한다. 새 초안은 이전 승인본을 대체하지 않고, 새 승인본의 종료·철회·만료가 과거 승인으로 자동 복귀하는 근거가 되지 않는다.
서명 키가 달라도 actor가 같으면 자기 승인이다. 미확정 정보가 있는 프로필을 승인할 수 있지만, 그 사실은 unknown으로 남으며 요구 적용·충족을 확정하지 않는다.

unknown·missing·known false·not_applicable은 구분한다. not_applicable 사실도 요구 제외 승인이 아니며 후속 검토 안내를 남긴다.
프로필 CLI의 validated 결과는 게이트 allow가 아니다. 미확정·정보 누락·적용 제외 검토는 review_required다.

## 영향과 경계

새 객체는 synthetic_reference·operational_approval=false로 제한한다. 현재 신뢰 역할 네 종류를 재사용하며 기관 실명 신원 연동을 주장하지 않는다.
신뢰 기준점을 외부에 보존해야 전체 이력의 롤백을 탐지할 수 있다. 파일 잠금이 없는 실행 환경은 거부한다.
기존 검사·게이트·서명 증적 계약을 바꾸지 않는다. 팩 발행·적용성·단계 게이트는 R7-C 이후다.
