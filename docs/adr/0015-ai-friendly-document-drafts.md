# ADR 0015: 공통 작성 정책을 적용한 설계 문서 초안

## 배경

하네스를 도입한 프로젝트는 여러 설계 문서를 작성한다. 문서의 구조와 서술 방식이 다르면 재사용과 검토가 어려워진다.
사용자는 AI Doc Ready의 행안부 AI 친화적 보고서 작성 원칙을 생성 문서에 적용하도록 요청했다.

## 결정

패키지에 [공통 작성 정책](../../govcode_harness/document_assets/DOCUMENT_WRITING_POLICY.md)을 포함한다.
`project document-kit`은 PRD·아키텍처·데이터 모델·규정 추적 매트릭스·ADR·백로그와 AGENTS.md를 새 폴더에 생성한다.
제목 단계를 일관되게 유지하고 문단은 서술형으로 작성한다. 비교표의 상단에는 번호와 제목을 둔다.
실제 근거가 없는 영역은 미제공으로 남기며 출처를 제공해도 권위나 적용성을 자동 확인하지 않는다.
행안부 원칙과 자체 보완 지침을 구분한다. 이 작성 정책을 법령 의무로 자동 등록하지 않는다.

입력은 일반 텍스트이며 명령이나 프롬프트로 실행하지 않는다. 기존 폴더와 문서를 덮어쓰지 않는다.
문서별 digest와 검토 대기는 별도 review.json에 기록한다. 이 기록은 서명 증적이나 승인 상태가 아니다.
AI Doc Ready는 버전을 고정하여 선택적으로 실행한다. 자동 다운로드나 기본 실행 의존성으로 추가하지 않는다.
도구의 실제 결과와 수동 검토를 함께 기록하며, 문서를 수정하면 검사를 다시 실행한다.

## 영향과 한계

이 기능은 초안 생성이며 실제 사업 설계를 자동 완성하지 않는다. 기존 문서의 일괄 변환과 HWPX 생성은 범위에 포함하지 않는다.
서술의 정확성·사실·수치·의미·병합의 적절성은 원문 대조와 사람의 검토가 필요하다.
향후 R7-F 문서 수정 제안은 같은 정책을 사용한다. 현재 기능을 R7-E/F 충족 평가의 구현 완료로 표시하지 않는다.
[실행과 검토 안내](../DOCUMENT_GENERATION.md)를 따른다.
