# ADR 0011: 제한된 모델 제안과 독립 격리 검증

상태: 로컬 참조 구현에 적용

## 결정

모델 입력은 허용한 구조 메타데이터뿐이며 기본 외부 전송은 비활성이다.
fixture와 실제 모델 실행을 구분한다. 제안은 권한이 아니며 독립 승인·원본/범위 대조·새 sandbox commit·정적/기능/감사/개인정보/실제 OS 격리 검증을 요구한다.
현재 검증 가능한 AST 부분집합과 합성 민원 함수 범위만 실행한다. 미지원·모의 실행·격리 불가는 undeterminable이다.
CPU·시간·출력·파일·프로세스를 제한하고 메모리는 RSS 감시임을 명시한다.
실제 모델의 품질·기관 반출 허용·일반 프로젝트 수정 실행은 별도 검증한다.
