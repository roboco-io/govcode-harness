## 분류 원칙

**확인한 법령상 의무**는 공식 조문에서 의무 내용을 확인했다는 뜻이다.
기관의 모든 법적 의무를 조사·확정했다는 뜻은 아니다.
예시 정책은 의무를 지원하는 설계 선택이며 법령 문구와 구분한다.
검사 통과를 적법성 또는 감사 적합성 인증으로 표현하지 않는다.

## 공식 근거와 확인 범위

- [개인정보 보호법 제29조](https://law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029332029): 시행 2026-09-11, 법률 제21445호. 안전조치 의무를 확인했다.
- [시행령 제30조](https://www.law.go.kr/LSW/lsLawLinkInfo.do?chrClsCd=010202&lsJoLnkSeq=900079401): 시행 2026-09-11, 대통령령 제36671호. 조문정보에서 구체적 조치 구조를 확인했다.
- [안전성 확보조치 기준 현행 전문 링크](https://law.go.kr/admRulLsInfoP.do?admRulSeq=2100000281400): 고시 제2026-9호, 표제 시행일 2026-07-01. 검색 본문에서 제8조를 일부 확인했다. 동적 본문과 부칙 전체를 확보하지 못했으므로 적용시점은 보류했다.
- [고시 제2025-9호 연혁·부칙 확인 대상](https://www.law.go.kr/admRulLsInfoP.do?admRulSeq=2100000265956&chrClsCd=010202): 제8조 개정에 시행 유예가 있다는 신호가 있어 원문·경과 규정 대조가 필요하다. 2026-10-31 전후 적용 차이를 검토 대상으로 남긴다. 확인 전 새 문구를 현재 의무로 집행하지 않는다.
- [시행령 제30조의2 연결 조문](https://law.go.kr/LSW/lsLinkCommonInfo.do?lspttninfSeq=66999): 공공시스템 해당 여부를 먼저 판단해야 하는 추가 조치를 확인했다.

검색 결과의 요약과 문서 표제 확인을 원문 전체 검토로 확대하지 않았다.
원문 파일을 내려받아 보관하지 않았으므로 Source의 snapshot_digest는 null이다.
법령 개정·부칙을 확인한 검토자가 기준일과 자료 버전을 고정한 뒤 규정 카탈로그를 갱신한다.

## 로그 유형별 적용 경계

| 기록 유형 | 목적 | 이 설계에서의 취급 |
| --- | --- | --- |
| 일반 앱·디버그 로그 | 장애 분석 | 민원 본문 제외, 허용 필드 중심으로 축소 |
| 개인정보처리시스템 접속기록 | 접근·처리 이력 추적 | 필수 항목을 보존하며 별도 적법성·안전조치·보관 기준 적용 |
| 하네스 검사 증적 | 개발 통제 검증 | commit·판정·정책·재검사 연결, 원문 민원 제외 |

앱 로그의 개인정보를 제거한다고 법정 접속기록의 필수 정보를 지우면 안 된다.
접속기록 보관기간을 하네스 증적에 일괄 복사하지 않는다.
하네스 증적이 공공기록물로 분류되는지는 기관의 기록관리 기준에 따라 추가 판단한다.

## 적용성 확정 절차

1. 시스템 기능, 개인정보 종류·규모, 계정 유형, 공공시스템 해당 여부를 담당자가 확인한다.
2. 기준일에 시행 중인 조문과 유예·경과조치를 원문에서 확인한다.
3. 적용/비적용/조건부 판단, 검토자, 근거, 날짜를 기록한다.
4. 법적 의무→통제→정책 연결에서 수동 통제와 자동 검사의 범위를 나눈다.
5. 승인된 규정·정책 버전으로 묶음을 발행한다. 미확정 항목은 준수 통계의 분모와 별도로 표시한다.

규정 검토의 주체는 기관 담당자다. AI가 만든 해석은 검토 제안으로만 저장한다.
