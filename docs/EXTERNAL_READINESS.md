# 실제 운영 적용 전 필요한 조건

로컬 참조 소프트웨어 구현과 실제 기관 운영 승인은 다른 결과다.
아래 항목은 합성 역할·개발 키·예시 데이터로 완료 처리하지 않았다.

| 항목 | 현재 상태 | 필요한 실제 근거·결정 |
| --- | --- | --- |
| 기관·시스템 범위 | 대한민국 일반 공공기관 기준, 특정 기관 미선정 | 개인정보 종류·규모·공공시스템 해당 여부·내부 규정 |
| 법령 추적 | 카탈로그·적용성·유효 구간 검증 구현, 실제 미확정 항목 유지 | REG-LOG-008 등 공식 원문·부칙·기준일 적용본 대조와 담당자 판단 |
| 실제 저장소·언어 | 합성 Python과 제한된 분석 범위 검증 | 대상 저장소·프레임워크·독립 정답 표본·범위 승인 |
| 원격 CI·보호 브랜치 | 로컬 게이트·비활성 제공자 예제 | 저장소·계정 권한·필수 검사와 신뢰한 CI commit 문맥 |
| 사용자·승인 권한 | 합성 admin-config 역할·실제 서명 알고리즘 | 실제 기관 신원 연동, 작성·승인·운영 역할, 권한 회수 |
| 운영 키·신뢰 루트 | 새 폴더의 합성 개발 키 | KMS/HSM·키 수명·교체·분실·철회·신뢰한 순번 관리 |
| 증적 보존 | 로컬 보관·hold·만료·서명 백업 복구 검증 | 법정 접속기록과 구분한 공공기록물 분류·보존·파기·복구 책임 |
| 저장소 내구·감사 | 서명·해시 사슬·외부 롤백 기준점 사용 | 운영 저장소·보관 잠금·백업·별도 감사 권한과 절차 |
| 실제 모델 | 모의 모델과 loopback 프로토콜·차단 경로 검증 | 모델·버전·자원·품질 평가·반출 승인·최소 입력 범위 |
| 기관 파일럿 | 합성 전후·관리 API·브라우저 확인 | 실제 기관·기간·표본·성공 기준·운영 책임자·보안 검토 |

사용자는 2026-10-29에 로컬 참조 구현을 완료 범위로 확정했다. 외부 운영 접속 정보는 제공되지 않았다.
원래 구현 요청과 기존 계획의 미결정 시 진행 가능한 경계에 따라 로컬·합성 소프트웨어를 완주하며, 이 선택을 실제 운영 작업 권한으로 해석하지 않는다.
실제 업무 CI 집행·기관 배포·실데이터 처리·기관 승인은 수행하지 않았다. 사용자 요청에 따른 코드와 안내 사이트 공개는 [공개 안내](PUBLICATION.md)에 기록하며 기관 운영 적용과 구분한다.
