# 온보딩·브로슈어 공개 사이트

사용자 요청: 솔루션 도입용 온보딩 가이드와 마케팅 브로슈어를 만들고 GitHub Pages로 배포한다.

Ruling: 정적 HTML/CSS/JS 사이트와 2쪽 PDF를 만든다. 사용자가 지정한 조직 roboco-io의 새 공개 govcode-harness-guide 저장소를 사용한다. 본 프로젝트도 roboco-io/govcode-harness로 공개한다. .runtime·비밀값은 제외한다. 두 리포는 사용자 선택에 따라 서브모듈 없이 버전별 링크로 연결한다. 사용자가 제작과 배포를 요청했으므로 구현·검증 후 게시한다.

## 디자인

- 색: 문서 흰색 #ffffff, 깊은 남색 #142943, 코발트 #2457d6, 연한 파랑 #e8f2ff, 본문 #30425b, 차단 표시 #b83c48.
- 글꼴: 한국어 시스템 고딕 본문, 명조 계열 큰 제목. 외부 폰트·분석·추적 서비스를 사용하지 않는다.
- 구성: 소개는 왼쪽 메시지와 오른쪽 검사 기록 흐름, 온보딩은 왼쪽 목차와 오른쪽 실행 안내, 브로슈어는 인쇄 가능한 2쪽.
- 특징: 민원 API의 deny→수정→allow→증적을 문서철 모양의 흐름으로 보여 준다. 카드 수치 장식보다 실제 결과와 지원 범위를 설명한다.

## 제작·검증·배포

1. 기존 실행 안내와 검증 기록에서 확인한 주장만 사용한다. 320개 시험은 v0.9.0 로컬 참조 검증으로 표시한다.
2. 설치·기본/전체 데모·결과 확인·관리 UI·CI 준비·운영 전 조건·문제 해결을 안내한다. 전체 OS 격리 검증은 macOS이며 fixture 모델임을 밝힌다.
3. 공개 소스 ZIP은 명시적 목록에서 만들고 .runtime·키·토큰·개인 설정·Git 정보를 제외한다. ZIP과 SHA-256을 함께 제공한다.
4. 모바일/데스크톱·키보드·내부 링크·다운로드·인쇄 PDF를 확인한다. PDF를 이미지로 렌더링해 한글과 페이지 넘침을 확인한다.
5. 전용 배포 저장소에 사이트만 커밋하고 push한다. Pages 활성화 후 실제 HTTPS 페이지와 다운로드를 확인한다.

실제 운영 준수 인증·기관 승인·실모델 성능·범용 언어 지원을 주장하지 않는다. GitHub Pages는 공개 안내 사이트이고 관리 화면이나 검사 서버를 호스팅하지 않는다.
