# 오철칙 연동 PoC

사용자가 승인한 다음 단계: 고정 버전의 별도 설치, 실제 예제 검사, 기존 검사와 비교, Finding·Decision·증적 연동.

## 설계

오철칙 1.11.2의 소스 commit 2a820e8cd7ade4c3060381198ed13bf3e6b43146을 고정한다.
외부 도구는 별도 Python 3.12 이상 환경에 설치하고 핵심 실행기의 표준 라이브러리 실행은 유지한다.
원본 저장소의 코드를 실행하거나 설정·Git 정보를 외부 도구에 전달하지 않는다. 고정된 snapshot의 Python 소스만 임시 작업 공간에 넣는다.
외부 결과의 원문·snippet·메시지는 증적에 저장하지 않는다. 규칙 ID·상대 위치·심각도·상태만 정규화한다.

기본 검사기는 유지한다. 선택적 --with-iron-laws 실행에서만 외부 검사와 결합한다.
오류 → 검토 필요 → 차단 → 통과 우선순위를 유지하고, 외부 도구 미설치·시간 초과·불완전·형식 오류는 통과하지 않는다.
외부 프로필은 법령상 의무와 구분한 로컬 예시 정책이다. 원래 개인정보 로깅 정책과 일반 외부 코드 위험 정책은 별도로 연결한다.

## 실제 확인에서 발견한 차이

원래 BEFORE_SOURCE의 request_body 로깅은 고정 오철칙 AI-112 프로필에서 지적되지 않았다.
이 때문에 기존 검사기를 대체하지 않으며, 보완 도구라는 상태를 유지한다.
원래 전후 코드를 오철칙에 맞춰 바꾸거나 누락을 숨기지 않는다.

## 구현 단위

- 외부 도구 설치·해시 잠금·프로필·어댑터와 실제 결과 기록.
- 실행기·CLI·정규화·증적 봉인 및 재검증 연결.
- 기존 corpus 비교와 실제 전후 데모.
- 문서·독립 검토·회귀 검사.

## 완료 조건

기존 104개 시험 유지, 추가 회귀 시험 통과, 실제 혼합 검사 deny→수정→allow와 증적 재검증.
원문 비저장, 정책·도구·설치 환경 변화 거부, 누락 증적과 외부 검사 비활성화 우회 거부.
비교 결과는 누락·오탐·분석 범위와 함께 기록한다. 정식 기본 도입 여부는 PoC 결과로 판단한다.
