# GovCode Harness v0.11.0 — 프로젝트 요구·산출물·단계 게이트

이 사전 릴리스는 사업 산출물·요구사항 추적과 기존 개인정보 로깅 검사를 로컬에서 연결한다. 기관 운영 배포와 전체 프로젝트 준수 인증은 포함하지 않는다.

## 추가한 기능

- R7-E는 commit 고정 JSON·Markdown 산출물, 요구→설계→시험→검토 추적과 서명 시험 증명을 검사한다.
- R7-F는 현재·후속 단계와 미확정·제외 상태를 구분하고 보완 작업을 안내한다. 독립 승인한 제한된 문서 변경은 원본을 보존한 새 commit에 적용한다.
- R7-G는 역할별 프로젝트 화면과 현재 단계 게이트를 제공한다. 현재 commit·프로필·규정 팩·검토·코드 검사와 실제 저장 증적을 다시 확인한다.
- R7-H는 원문 없는 서명 증적, 보존 기한·hold·부모 관계·역할별 권한·백업 및 복구를 제공한다.
- R7-I는 요구 8개와 두 분야의 전후 실행을 연결한다. 최종 결과는 현재 단계 충족 5개·후속 1개·승인 제외 2개다.

프로젝트 기능을 govcode_harness/project에 모으고 이전 import와 CLI를 유지한다. 기존 프로필·규정 팩·문서 초안과 첫 로깅 사례도 유지한다.

## 설치와 실행

```sh
git clone --branch v0.11.0 --depth 1 https://github.com/roboco-io/govcode-harness.git
cd govcode-harness
python3 scripts/setup_reference.py
.runtime/reference-venv/bin/python -m govcode_harness project-demo --output .runtime/my-project-demo
```

전체 참조 환경은 Python 3.12 이상·Git·uv를 사용한다. 검증 환경은 macOS다. 출력은 새 비공개 폴더를 사용한다. 기본 로깅 데모는 Python 3.10 이상과 Git으로 실행할 수 있다.
wheel은 `python -m pip install './govcode_harness-0.11.0-py3-none-any.whl[reference]'`로 설치한다. 선택 의존성 다운로드에는 네트워크가 필요하다.

[전체 실행과 화면](../PROJECT_REFERENCE_RUNBOOK.md), [평가와 문서 수정](../PROJECT_ASSESSMENT_RUNBOOK.md), [단계와 보관](../PROJECT_STAGE_EVIDENCE_RUNBOOK.md)을 따른다.

## 검증과 배포물

전체 739개 시험과 별도 설치 패키지의 실제 통합 실행을 검증한다. 최종 배포 검증 수치와 파일 해시는 릴리스 첨부 VALIDATION.json 및 SHA256SUMS에 기록한다. 개발 단계의 상세 결과는 [완료 보고](../R7_COMPLETION_REPORT.md)와 [검증 기록](../VALIDATION.md)에 보존한다.
GitHub 릴리스는 wheel·소스 배포본·LICENSE·NOTICE·검증 요약·SHA256SUMS를 제공한다. .runtime의 개발 키·토큰·설정·생성 증적은 배포하지 않는다.

## 적용 범위와 후속 작업

자료·역할·키는 합성 참조다. 실제 기관 규정 적용본·신원·운영 키·보존 분류·원격 CI·실모델·기관 파일럿은 후속 조건이다. 큰 저장소·새 언어·HWPX/PDF/Office와 다른 분야 팩은 지원 확대 대상이다.
현재 단계 allow를 전체 프로젝트 완료나 법적 준수 인증으로 표시하지 않는다. 법령상 의무·기관 규정·계약·권고·예시 정책·미확정 정보를 구분한다.
서명과 로컬 hash chain은 WORM·KMS를 대신하지 않는다. 롤백 탐지에는 외부 보호 checkpoint가 필요하다.

## 라이선스와 안내 사이트

프로젝트는 Apache-2.0이다. 선택적 Iron Laws의 MIT 표시를 유지한다. 별도 가이드는 CC BY 4.0이며 기존 가이드 버전은 유지한다. 최신 R7 실행은 이 릴리스에 포함한 실행 안내를 따른다. GitHub Pages는 정적 안내 사이트이며 검사기나 기관 운영 서버를 호스팅하지 않는다.
