# GovCode Harness v0.10.0 — 프로젝트 프로필·규정 팩·AI 친화적 문서

이 사전 릴리스는 공공 프로젝트의 요구를 파악하고 검토·승인·증적을 연결하는 로컬 참조 구현을 확장한다.
다양한 공공 프로젝트에서 비개발자가 안전하게 AI와 업무 도구를 만드는 경험을 목표로 한다. 전체 사용자 경험의 완성을 뜻하지 않는다.

## 추가한 기능

- R7-A 공통 계약은 프로젝트 범위·버전·digest 참조를 검증한다. 계약 스키마를 설치 패키지에 포함한다.
- R7-B 프로젝트 프로필은 불변 버전, 독립 승인, 미확정 정보, 승인 만료·철회와 동시 변경 검증을 제공한다.
- R7-C 규정 팩은 실제 서명 발행, 독립 승인, 의존성 잠금, 만료·철회 검증과 보호된 철회 정보 digest 대조를 제공한다.
- R7-D 적용성 판단은 알려진 값·false·미확정 정보를 구분한다. 제외 판단과 법적 근거의 적용에는 독립 검토를 요구한다.
- 문서 생성은 공통 작성 정책에 따라 PRD·아키텍처·데이터 모델·규정 추적 매트릭스·ADR·백로그 초안을 만든다. AGENTS.md와 작성 정책을 함께 제공하고 검토 메모는 분리한다.

개인정보 로깅의 기존 탐지·차단·수정·재검사·증적 생성과 로컬 정책·승인·보관·관리 화면 기능을 유지한다.

## 실행

저장소를 새 폴더에 받은 뒤 프로젝트 루트에서 실행한다.

```sh
git clone --branch v0.10.0 --depth 1 https://github.com/roboco-io/govcode-harness.git
cd govcode-harness
python3 -m govcode_harness demo --output .runtime/first-slice
python3 scripts/setup_reference.py
.runtime/reference-venv/bin/python -m govcode_harness project profile-demo --output .runtime/profile-demo
.runtime/reference-venv/bin/python -m govcode_harness project pack-demo --output .runtime/pack-demo
.runtime/reference-venv/bin/python -m govcode_harness project document-kit --output .runtime/design-documents
```

기본 데모는 Python 3.10 이상과 Git으로 실행한다. 서명·규정 팩 참조 환경은 Python 3.12 이상과 uv를 사용한다.
전체 회귀 검증은 macOS의 로컬 API·OS 격리 환경에서 수행한다. 출력 폴더는 매번 새 경로를 사용한다.
wheel은 `python -m pip install './govcode_harness-0.10.0-py3-none-any.whl[reference]'`로 선택 의존성과 함께 설치할 수 있다.
이 설치 명령의 선택 의존성 다운로드에는 네트워크가 필요하다. 조직의 승인된 배포 경로를 사용한다.

[프로필 실행 안내](../PROJECT_PROFILE_RUNBOOK.md), [팩과 적용성 실행 안내](../RULE_PACK_APPLICABILITY_RUNBOOK.md), [문서 생성 안내](../DOCUMENT_GENERATION.md)를 따른다.

## 검증과 배포물

전체 439개 시험이 통과했다. 실패·오류·건너뜀은 0개다. 배포 wheel의 실제 데모와 생성 문서 8개의 구조 검사도 확인했다.
이 릴리스의 검증 범위와 실제 결과는 [검증 기록](../VALIDATION.md)을 따른다.
GitHub 릴리스에는 wheel, 소스 배포본, LICENSE, NOTICE, 검증 요약과 SHA256SUMS를 제공한다.
소스 배포본에는 실행 안내·고정 의존성 목록·예시 규정 팩·테스트와 fixture를 포함한다.

## 검토가 필요한 범위

실행은 합성 참조이며 실제 기관의 승인이나 파일럿 완료가 아니다. 법령상 확정 의무·기관 규정·예시 정책·미확인 요구를 구분한다.
적용성 판단 완료는 요구 충족, 검사 통과, 병합·배포 허용을 뜻하지 않는다. R7-E~I의 산출물 검사·충족 평가·UI·새 단계 게이트 연결은 후속 범위다.
외부 철회 정보와 신뢰 키의 최신성, 보호된 기준 digest·checkpoint는 도입 기관이 관리해야 한다. 오프라인 실행은 전달되지 않은 철회를 즉시 알 수 없다.
문서 생성은 초안 작성이며 AI Doc Ready를 자동 설치하거나 실행하지 않는다. 구조 검사와 별도로 사실·수치·의미를 원문과 대조해야 한다.
검사 통과를 법적 준수 인증이나 행안부 공식 인증으로 표시하지 않는다.
