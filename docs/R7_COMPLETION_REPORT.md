## 최종 검증

전체 **739개 시험이 통과**했다. 기존 553개를 유지하고 신규 186개를 추가했다.
실패·오류·건너뜀은 0개이며 실행 시간은 413.396초다. 원래 회귀 시험 파일의 digest가 바뀌지 않았고 중복 TestCase 수집도 없음을 확인했다.
실행 명령·범위와 원본 기록은 [검증 기록](VALIDATION.md)을 따른다.

별도 계약 인수 24개는 정상 8·차단 8·미확정/미검증 8을 사전 분류하고 기대 결과를 바꾸지 않고 통과했다.
작성자는 R7-I 참조 구현을 읽지 않았다. 다만 fixture를 읽던 중 기존 F 개발 시험 일부가 함께 노출됐으므로 전체 F 구현에 대한 완전 블라인드 표본으로 표현하지 않는다.
이는 별도 작성한 R7-I 계약 인수이며, 기존 R7-E 독립 표본과 구분한다.

실제 지속 실행과 프로젝트 밖의 별도 설치 패키지 실행에서 각각 **34개 통합 검증**을 통과했다.
최종 전체 8개 중 현재 단계 충족 5개·후속 1개·승인 제외 2개를 유지했다. 전체 프로젝트 완료나 100% 준수로 표시하지 않았다.
실제 브라우저에서 역할별 화면과 390px 폭을 확인했다. 작성자의 승인 화면은 숨기고 검토자에게만 표시하며, 토큰은 영구 저장소에 남지 않았다.

## 반복과 독립 검토

Ralph Loop 1.0.1의 원래 설정·종료 훅을 .runtime/ralph-r7에서 실제 호출했다.
Codex에 자동 종료 훅을 설치했다고 표현하지 않는다. scripts/ralph_r7_checkpoint.py가 같은 작업 프롬프트와 반복 상태·실패·수정·시험·검토를 보존한다.
완료 검사는 F~I 인수·전체 회귀·설치 검증·최종 APPROVED·소스 digest·실제 요구 8개 결과를 모두 요구한다.
Ralph 상태·원본 훅 출력·최종 증거는 .runtime/ralph-r7에 보관한다. 원래 R1~R6의 과거 반복 기록은 덮어쓰지 않았다.

독립 검토에서 도구 지침 파일의 변경 대상 오분류, 실제 Git 작업 루트와 출력 경계, 안전하지 않은 Git 설정 처리,
만료 검토의 갱신 경로를 발견하고 각각 재현 시험으로 수정했다. 별도 최종 검토에서도 추가 지적이 없었다.
한 검토 실행은 서비스 필터로 최종 판정 전에 종료돼 승인으로 세지 않았고, 다른 읽기 전용 검토로 다시 확인했다.

## 남은 외부 조건

실제 기관·법령 적용본·내부 규정·계약·보존 분류·신원·운영 키·원격 CI·운영 파일럿은 미확정이다.
실모델은 실행하지 않았다. 합성 모델·구조 검사 결과를 실제 생성 품질이나 사실 정확성으로 일반화하지 않는다.
서명과 로컬 hash chain은 WORM·KMS·기관 승인·감리·검수를 대신하지 않는다.
전체 로컬 롤백 탐지에는 외부 보호 checkpoint가 필요하며, 오프라인 철회 전파와 실제 시험 어댑터 운영도 별도 관리해야 한다.
큰 저장소·새 언어·HWPX/PDF/Office·다른 분야 팩·비개발자의 자연어 제작 경험은 후속 범위다.
[실제 운영 준비](EXTERNAL_READINESS.md)와 [전체 실행](PROJECT_REFERENCE_RUNBOOK.md)을 따른다.
