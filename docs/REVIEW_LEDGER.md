# 독립 검토와 수정 기록

검토는 서로 다른 구현·검토 에이전트가 로컬 합성 참조 코드에 수행했다. 실제 기관 보안 승인이나 유권해석이 아니다.

| 검토 범위 | 발견한 문제 | 수정·재검증 | 최종 상태 |
| --- | --- | --- | --- |
| 정책·예외·CI 권한 | 철회된 예외 서명자·서명 기록 미반영 | 양쪽 서명자·서명 기록의 철회 전파, 실제 서명 회귀 | 승인 |
| 예외의 대상 범위 | 수정 가능한 실행 ID에만 의존 | commit·현재 도구·정책·재계산한 탐지 의미 digest에 결합 | 승인 |
| 증적 내보내기 | 검증 전후의 다른 메타데이터가 혼합될 수 있음 | 검증된 manifest에 같은 바이트를 결합하고 신원·범위를 대조 | 승인 |
| 검증기와 해시 | 의미 검사와 해시가 서로 다른 재읽기를 사용 | 모든 파일과 조상 기록을 동일한 읽기 캡처로 검증 | 승인 |
| 모델·수정·관리 API·UI | 범위·서명·재사용·반출·격리·역할 검토 | 독립 검토와 합성 시험, 실제 OS/HTTP 양성·음성은 별도 전체 실행 | 승인 |

정책 재검토는 수정 후 실제 서명 회귀와 59개 관련 시험으로 확인했다.
증적의 마지막 일관성 검토는 읽기 전용 소스 검토이며 시험 재실행으로 가장하지 않는다.
모델·관리 검토의 제한 실행에서는 OS/HTTP 관련 4개가 건너뛰어졌음을 명시했다.
최종 전체 시험은 허용된 로컬 환경에서 320개를 실패·건너뜀 없이 실행해 해당 실제 경로까지 확인했다.
한 검토 실행은 서비스 필터로 완료되지 않았으며 승인으로 세지 않았다. 이후 별도의 데이터 일관성 검토를 완료했다.
