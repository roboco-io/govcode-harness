# 독립 검토와 수정 기록

검토는 서로 다른 구현·검토 에이전트가 로컬 합성 참조 코드에 수행했다. 실제 기관 보안 승인이나 유권해석이 아니다.

| 검토 범위 | 발견한 문제 | 수정·재검증 | 최종 상태 |
| --- | --- | --- | --- |
| 정책·예외·CI 권한 | 철회된 예외 서명자·서명 기록 미반영 | 양쪽 서명자·서명 기록의 철회 전파, 실제 서명 회귀 | 승인 |
| 예외의 대상 범위 | 수정 가능한 실행 ID에만 의존 | commit·현재 도구·정책·재계산한 탐지 의미 digest에 결합 | 승인 |
| 증적 내보내기 | 검증 전후의 다른 메타데이터가 혼합될 수 있음 | 검증된 manifest에 같은 바이트를 결합하고 신원·범위를 대조 | 승인 |
| 검증기와 해시 | 의미 검사와 해시가 서로 다른 재읽기를 사용 | 모든 파일과 조상 기록을 동일한 읽기 캡처로 검증 | 승인 |
| 모델·수정·관리 API·UI | 범위·서명·재사용·반출·격리·역할 검토 | 독립 검토와 합성 시험, 실제 OS/HTTP 양성·음성은 별도 전체 실행 | 승인 |

정책 재검토는 수정 후 실제 서명 회귀와 59개 관련 시험으로 확인했다.
증적의 마지막 일관성 검토는 읽기 전용 소스 검토이며 시험 재실행으로 가장하지 않는다.
모델·관리 검토의 제한 실행에서는 OS/HTTP 관련 4개가 건너뛰어졌음을 명시했다.
최종 전체 시험은 허용된 로컬 환경에서 320개를 실패·건너뜀 없이 실행해 해당 실제 경로까지 확인했다.
한 검토 실행은 서비스 필터로 완료되지 않았으며 승인으로 세지 않았다. 이후 별도의 데이터 일관성 검토를 완료했다.

## 구조 정리와 R7-E 개발 독립 검토 — 2026-10-30

구조 정리 후 기존 439개와 호환성 9개를 합한 448개 전체 회귀를 확인했다. 기존 시험 소스는 변경하지 않았다.
별도 작성자는 새 구현과 개발자 시험을 읽지 않고 정상 8개·차단 결함 8개·미검증/미지원 8개의 인수 표본을 작성했다.
실제 Git commit과 실제 서명을 사용한 24개 인수 시험은 기대 분류를 바꾸지 않고 통과했다.

읽기 전용 검토자는 다른 정상 경로가 있을 때 필수 산출물의 막힌 가지가 통과하는 문제를 재현했다.
검사기는 모든 필수 산출물이 요구에서 도달하고 검토 기록까지 이어지는 경로 위에 있는지 확인하도록 수정했다.
필수 설계·시험 계획·시험 결과의 막힌 가지를 거부하고 정상 공유 경로와 종점 검토 기록을 유지하는 회귀 시험을 추가했다.

통합 검증에서는 외부 도구 설정과 다시 서명한 시험 결과가 서명 팩의 어댑터 선언을 바꾸는 문제를 재현했다.
현재는 원본 팩 검증 후 check_specs와 외부 도구 설정을 대조하고 다른 어댑터를 거부한다. 실제 서명 팩을 사용한 음성 시험을 유지한다.
이후 별도 최종 검토자는 새 캡처 검증·추적/시험 증명·팩 연결의 전체 검토 자료를 확인하고 APPROVED로 판정했다.
전체 회귀와 설치 패키지 결과는 [검증 기록](VALIDATION.md)을 따른다. 이 검토는 R7-F~I의 충족 평가·단계 게이트·기관 운영 승인을 대신하지 않는다.

## R7-F~I 순차 랄프 독립 검토 — 2026-10-30

F 평가·문서 변경, G 화면·단계 게이트, H 실제 보관·복구와 G/H 연결을 각각 읽기 전용으로 검토했다.
지침/설정 파일을 설계로 오분류하는 경로, 원래 작업 루트·Git 메타데이터와 출력 경계, Git 설정과 작업 폴더 확인,
만료된 검토를 보존하면서 갱신하는 경로를 실제 재현 후 회귀 시험으로 수정했다.
각 범위의 재검토와 새 최종 I 통합 검토가 APPROVED였다. 한 검토 실행의 서비스 필터 종료는 승인에서 제외했다.
별도 인수 작성자는 I 구현을 읽지 않고24개 기대 분류를 고정했다. fixture 열람 중 기존 F 시험 일부가 노출돼 F 완전 블라인드로는 주장하지 않는다.
최종739개 전체 회귀·실제 브라우저·별도 설치 패키지 증거는 [검증 기록](VALIDATION.md)에 있다.
